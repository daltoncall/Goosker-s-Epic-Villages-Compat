# Goosker-s-Epic-Villages-Compat
A mod that offers configuration and compatibility between the Epic Structures: Villages mod and any other village mod.

The mod [Epic Structures: Villages](https://modrinth.com/datapack/epic-structures-villages) only has 3/5 villages included. This mod allows for those 3 epic villages to spawn as well as whatever other village mod you have activated. You can use the config file to toggle each village type you'd prefer to spawn.

Config file location: config/gooskers_epic_villages_compat.properties

Default:
```
# Village values: true = Enable generation | false = Disable generation | 50_50 = equal chance per each village

epic_plains=true
epic_snowy=true
epic_taiga=true

# [Bonus Feature] Luki's Grand Capitals
no_center_structure_gen=false

```

I'm new to coding. Please feel free to build upon my work and/or use this in your modpack!

This mod does not contain any assets from any village mod, and is purely a utility mod that requires Epic Structures: Villages be installed.

I recommend using the mod [Structurify](https://modrinth.com/mod/structurify) to manage village size, generation spacing, and biome placement.
